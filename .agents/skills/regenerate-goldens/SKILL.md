# Regenerate golden fixtures

Golden tests compare u50's formatter output byte-for-byte against fixtures
generated by style50 3.0.0 itself. Two invariants must hold after any
regeneration:

1. `format(dirty) == expected` (transformation), and
2. `format(expected) == expected` (fixed point / idempotency).

## When

- A backend version in `PINNED_VERSIONS` / `tests/tool-versions.txt` is
  bumped (always bump both together — `tests/tool-versions.txt` is the
  single source of truth and what CI installs).
- A dirty fixture is adjusted or replaced.

## Procedure

The oracle is `style50 -o format`; the second command below must show
**no diff**:

```sh
cd u50_style/tests/fixtures
cp <lang>/dirty.<ext> /tmp/dirty
style50 -o format /tmp/dirty.<ext> > <lang>/expected.<ext>
style50 -o unified <lang>/expected.<ext>   # must print no +/- lines
```

For backend upgrades, regenerate **all** languages whose output changed;
the pinned versions and the goldens move together.

## Fixed-point construction (new/replaced fixtures)

1. Start from the minified upstream source `dirty0`.
2. Iterate `X_{i+1} := style50 -o format X_i` (up to 25 passes) until
   `X_{i+1} == X_i` byte-equal. The converged `F := X_i` becomes `expected`.
3. Set `dirty := X_{n-1}` (the iterate before convergence) so
   `format(dirty) == expected` by construction. Languages converging on the
   first pass use `dirty := dirty0` instead. A vacuous `dirty == expected`
   fixture fails the golden test's `assert_ne!` guard.
4. If a language does not converge in 25 passes, shrink/replace the source
   (truncate the minified lib at a top-level statement boundary that still
   parses) and restart.

## Provenance

Fixtures are large real-world minified sources (cJSON, JsonCpp, Guava,
Werkzeug, jQuery, normalize.css, Bootstrap, Supabase). Any change to a
fixture's upstream source, license, or minification must be reflected in
[`tests/fixtures/NOTICE.md`](../../../u50_style/tests/fixtures/NOTICE.md).

## Verify

```sh
U50_STYLE_GOLDEN=1 cargo test -p u50_style --test golden
```

All languages must PASS (no `skip` — run `u50 --setup` if the cache is
missing the upgraded backend). Then run the full gate ladder
(`.agents/workflows/quality-gates.md`) before committing.
